# EstacionateYa

MVP de estacionamiento colaborativo: lugares en la calle en vivo y garages privados por hora.
HTML + CSS + JavaScript (ES modules) con Firebase Auth y Cloud Firestore.

## Estructura
- `index.html` – pantallas de acceso y app
- `css/styles.css` – estilos mobile-first
- `js/firebase.js` – configuración de Firebase
- `js/auth.js` – registro, ingreso y sesión
- `js/spots.js` – guardar y escuchar spots en tiempo real
- `js/app.js` – navegación e interfaz
- `firestore.rules` – reglas de seguridad
